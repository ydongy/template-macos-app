# v1.0 First release

> Issue: #1 · Requirement: `docs/spec.md#acceptance-checklist` · Screens: `design/screens/example.html` · Status: planned

## Goal

On any Mac running macOS 26, a user downloads the dmg from the website, installs it by double-click with no Gatekeeper warning, sees the menu bar icon, opens the panel with the Example screen in all four states, and later receives updates inside the app. Every item of the spec's acceptance checklist has been verified on a clean Mac. The baseline already contains the app, the package, the tests and the release scripts; this release makes them installable and trustworthy.

## Scope

- **Features in 1.0**: the menu bar panel with the Example screen (loading, loaded, empty, failed), refresh and retry, the footer with "Check for Updates…" and "Quit", nine languages that follow the system language. See [docs/spec.md](../spec.md).
- **Version and metadata**: `MARKETING_VERSION` is `1.0.0`; the build number is raised by `scripts/bump.sh`. `LICENSE` is the Terms of Service; the README does not say "open source". `CHANGELOG.md` starts at 1.0.0.
- **Distribution**: the website and Cloudflare R2 (`dl.example.com`), described in [docs/website.md](../website.md).
- **Signing and packaging**: Hardened Runtime, Developer ID Application signature, notarization and stapling, dmg, `scripts/release.sh`. Without the certificate the script builds an unsigned dmg for testing.
- **Updates**: Sparkle with a signed `appcast.xml`; the public key is set in `SPARKLE_PUBLIC_KEY`.
- **Clean-Mac acceptance** of the dmg install, of a first launch with no data file, and of an update from a lower build.

## Non-goals

- A Settings window, an About screen, notifications and login item.
- Paid plans and licensing.
- Windows, Linux and the App Store.

## Decisions

- Distribution is the product website plus Cloudflare R2, with Sparkle updates from the first release.
- The app is closed source under the Terms of Service in `LICENSE`.
- The architecture is recorded in [0001](../adr/0001-templatecore-package-with-mainactor-default-isolation.md).
- Release builds contain no Mock or Preview symbols; `FORBID_SYMBOLS` in `Config/release.conf` makes the release script check it.

## Tests

- Unit tests (Swift Testing): `ExampleModelTests` (phases), `LiveExampleSourceTests` (missing, valid and malformed file), `AppLanguageTests`, `UICopyTests`, `ProductLinksTests`, `DesignTokensTests`, `AppBundleTests` (Info.plist keys and the updater switch), `LocalizationCatalogTests` and `UserVisibleStringsTests` (every key in every language, no UI literal outside the catalog).
- Release scripts: `scripts/test-release.sh`; `python3 scripts/test_website_changelog.py` for the public changelog lint; `python3 scripts/scan_secrets.py` for credentials.
- By hand on a Mac: all four states in light and dark against `design/screens/example.html`, VoiceOver through the panel, truncation in each language, the dmg install on a clean Mac, one real update from a lower build.
