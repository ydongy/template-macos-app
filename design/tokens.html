Palette

DesignTokens.Palette uses system semantic colors (.primary, .secondary, controlBackgroundColor, separatorColor, .accentColor, .green, .orange, .red); light and dark come from the system appearance and there are no per-mode overrides in code. The swatches are approximations of the macOS system colors for the mockups: the real values change with the OS version, the accent color and accessibility settings such as Increase Contrast.

The status symbol takes Palette.ok for checkmark.circle.fill and Palette.attention for exclamationmark.triangle.fill; status is also carried by the shape. Palette.surface, Palette.hairline and Palette.accent are declared for screens that need them; the Example screen uses the system divider and the link button style.
